# ربات کامل آموزشی فیزیک متوسطه دوم

این نسخه نسبت به نسخه قبلی کامل‌تر است و هسته هوش مصنوعی دارد.

## قابلیت‌ها

- پاسخ هوشمند به سؤال‌های فیزیک متوسطه دوم
- حل مرحله‌به‌مرحله مسائل محاسباتی
- دریافت سؤال به صورت متن
- دریافت عکس سؤال و تحلیل تصویر
- دکمه 👍 و 👎 برای ارزیابی هر پاسخ
- دریافت نظر متنی دانش‌آموز
- ثبت کاربران و سؤال‌ها در SQLite
- پنل مدیریت با /admin
- آمار کاربران و سؤال‌ها
- مشاهده آخرین سؤال‌ها
- مشاهده پاسخ‌های نامطلوب
- ارسال پیام همگانی
- مسدود کردن کاربر

## نکته درباره هزینه

این ربات از OpenAI API استفاده می‌کند و مصرف API جدا از اشتراک ChatGPT محاسبه می‌شود. مدل پیش‌فرض در این نسخه `gpt-5.6-luna` است که برای کارهای پرتعداد و حساس به هزینه طراحی شده است.

## راه‌اندازی ساده در ویندوز

1. Python 3.11 یا جدیدتر را نصب کنید.
2. این پوشه را باز کنید.
3. فایل `run_windows.bat` را اجرا کنید.
4. توکن Telegram، کلید OpenAI و ID عددی تلگرام خودتان را وارد کنید.

### ساخت Telegram Bot

در Telegram به @BotFather بروید:
`/newbot`

توکن را دریافت کنید و فقط داخل اجرای ربات وارد کنید. توکن را برای کسی نفرستید.

### گرفتن ADMIN_ID

ربات‌های عمومی دریافت ID در تلگرام وجود دارند. عدد ID خودتان را پیدا کنید و هنگام اجرای فایل وارد کنید.

## استفاده

در ربات:
`/start`

برای خودتان:
`/admin`

دانش‌آموز می‌تواند:
- متن سؤال را بفرستد.
- عکس سؤال را بفرستد.
- بعد از پاسخ، مفید/غیرمفید را انتخاب کند.
- نظر اصلاحی ارسال کند.

## فایل پایگاه داده

`physics_bot.db`

در همین پوشه ساخته می‌شود و اطلاعات کاربران، سؤال‌ها و بازخوردها را نگه می‌دارد.

## نکته امنیتی

کلید OpenAI و توکن Telegram را در گروه، کانال، گیت‌هاب یا برای افراد دیگر منتشر نکنید.

## مرحله حرفه‌ای بعدی

برای استفاده واقعی با تعداد زیاد دانش‌آموز، بهتر است ربات روی یک سرور ابری همیشه روشن اجرا شود و محدودیت مصرف، احراز هویت مدیر، پشتیبان‌گیری و گزارش هزینه نیز اضافه شود.
